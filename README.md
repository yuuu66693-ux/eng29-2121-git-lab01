# DC Circuit Calculator

ใช้สำหรับเรียนLab คอมโปรไฟฟ้า

โปรแกรมคำนวณวงจรไฟฟ้ากระแสตรง (DC Circuit Calculator) ถูกพัฒนาขึ้นเพื่อช่วยในการคำนวณค่ากระแสไฟฟ้า (Current) และกำลังไฟฟ้า (Power) ของวงจรตัวต้านทานได้อย่างถูกต้องและรวดเร็ว เหมาะสำหรับนักเรียน นักศึกษา และผู้ที่สนใจใช้เป็นเครื่องมือช่วยตรวจสอบความถูกต้องของการคำนวณทางไฟฟ้า

ผู้ใช้สามารถกำหนดแรงดันไฟฟ้า (V) และค่าความต้านทาน (R) เพื่อคำนวณกระแสไฟฟ้าจากสูตร I = V / R และกำลังไฟฟ้าจากสูตร P = V x I โดยโปรแกรมจะแจ้งข้อผิดพลาดหากค่าความต้านทานเป็นศูนย์หรือติดลบ

เริ่มใช้งานได้ด้วยคำสั่ง `python electrical.py` ตัวอย่างแรงดัน 12 V และความต้านทาน 6 ohm จะแสดงผล:

```text
Current: 2.0 A
Power: 24.0 W
```
